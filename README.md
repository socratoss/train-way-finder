## Overview

train-way-finder is a powerful developer tool for building and managing railway navigation systems. It combines route planning, data management, and testing features within a Django framework to support transportation operations.

**Why train-way-finder?**

This project aims to simplify the development of railway route management and navigation solutions. The core features include:

* **🌐 Route Finder:** Constructs city graphs and filters feasible travel paths based on constraints.
* **🛠️ CRUD Operations:** Provides user-friendly interfaces for managing cities, trains, and routes.
* **✅ Automated Testing:** Ensures core functionalities are reliable and maintainable.
* **⚙️ Admin Integration:** Simplifies data oversight with Django's admin interface.
* **✨ Seamless Web Experience:** Uses templates and forms for intuitive user interactions.

## Getting Started

### Prerequisites

This project requires the following dependencies:

* **Programming Language:** Python
* **Package Manager:** Conda

### Installation

Build train-way-finder from the source and install dependencies:

1.  **Clone the repository:**

    ```sh
    git clone [https://github.com/socratoss/train-way-finder](https://github.com/socratoss/train-way-finder)
    ```

2.  **Navigate to the project directory:**

    ```sh
    cd train-way-finder
    ```

3.  **Install the dependencies:**

    Using `conda`:

    ```sh
    conda env create -f conda.yml
    ```
